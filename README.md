# hub-notebooks


## Sobre o projeto ##

Este aplicativo foi desenvolvido para centralizar e facilitar o acesso aos notebooks armazenados no Google Colab, organizando-os de forma clara por ano e semestre. A proposta é oferecer uma visualização simples e direta, eliminando a necessidade de buscar manualmente os arquivos no Google Drive.

Por meio de um menu lateral, é possível selecionar o ano desejado e, em seguida, acessar o notebook correspondente ao 1º ou 2º semestre com um único clique, sendo redirecionado diretamente para o Google Colab.
